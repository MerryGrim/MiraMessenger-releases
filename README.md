# Mira Messenger — LAMBDADEV

## Release 0.15.0

[Скачать подписанный APK](https://github.com/MerryGrim/MiraMessenger-releases/releases/download/v0.15.0/MiraMessenger-release.apk)

Постоянный пакет `chat.mira.messenger`, versionCode 17, Android 8.0+, arm64/x86_64.
Устанавливайте поверх Release 0.14 без удаления приложения. Постоянная подпись
сохранена; прежние APK остаются в предыдущих релизах.

В этой версии:

- Смена кода восстановления существующей защиты с проверкой доступных секретов.
  Активная резервная копия и криптографическая идентичность сохраняются.
- Если секретов нет на телефоне, сначала импортируйте прежний сохранённый код.
  Новый код надо сохранить отдельно и подтвердить последние восемь символов.
- Защищённая временная копия нового кода остаётся на телефоне до подтверждения.
  При ошибке сохранения показано предупреждение и повторная смена заблокирована.
- Согласованные светлая и тёмная темы: синие акценты и нейтральные поверхности.
- Единые кнопки основных, дополнительных и опасных действий: общий размер,
  скругление, отступы, состояния доступности и цвета.

Matrix, E2EE, звонки, Firebase, собственный канал уведомлений, голосовые,
автоудаление, пересылка, QR-контакты, ПИН и встроенные GitHub-обновления сохранены.
Проверка обновления сначала показывает изменения, затем предлагает фоновое
скачивание. Установку подтверждает Android.

Смена кода не восстанавливает отсутствующие ключи сообщений. Прежний код больше
не открывает текущее защищённое хранилище; ранее полученные секреты и устройства
этим не отзываются. Потеря телефона/Keystore может уничтожить временную копию,
поэтому сохраняйте код отдельно. Автоудаление не гарантирует удаления всех
чужих копий истории. На другом homeserver звонки и push требуют совместимой
настройки сервера.
