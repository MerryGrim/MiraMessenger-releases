# Mira Messenger APK releases

This is the public distribution repository for Mira Messenger, an Android
Matrix messenger. Mira's project repository is private. This repository holds
APK release assets, update manifests and notices for bundled components.

The first APK release is being prepared; no APK has been published yet.
Once a verified release is published as Latest, these fixed links will serve it:

- [MiraMessenger.apk](https://github.com/MerryGrim/MiraMessenger-releases/releases/latest/download/MiraMessenger.apk)
- [Update manifest](https://github.com/MerryGrim/MiraMessenger-releases/releases/latest/download/update-manifest.json)
- [Release history](https://github.com/MerryGrim/MiraMessenger-releases/releases)

The Android client verifies the downloaded APK's size, SHA-256, package,
version and signing certificate before opening the system installer.
Android requires the user's confirmation to install an update.
