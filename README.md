# Mira Messenger — LAMBDADEV

## Release 0.18.0

[Скачать подписанный APK](https://github.com/MerryGrim/MiraMessenger-releases/releases/download/v0.18.0/MiraMessenger-release.apk)

Пакет `chat.mira.messenger`, versionCode 20, Android 8.0+, arm64/x86_64.
Устанавливайте поверх Release 0.17 без удаления приложения. Постоянный ключ
подписи сохранён; предыдущие APK остаются в своих релизах.

В этой версии:

- «Прочитано» в шторке отмечает сообщения до конкретного события приватной Matrix-отметкой. Новые сообщения сохраняются в уведомлении.
- «Без звука на час» временно отключает сообщения этого чата на этом устройстве. Звонки и правила на сервере сохраняются; срок истекает без сети.
- При PIN действия требуют разблокировки и подтверждения. Быстрый ответ остаётся доступен.
- Жалобы получают причину, комментарий, предпросмотр и подтверждённый результат. Текст выбранного сообщения прикладывается только по явному согласию; поддержка жалоб на пользователя/чат зависит от homeserver.
- Безопасная очистка удаляет старые скачанные копии медиа, сохраняя ключи, историю, записи, подготовленные вложения и обновление.
- В «О приложении» доступен локальный диагностический отчёт без сообщений, адресов аккаунтов, токенов и ключей.
- Для im.w2o.ru развёрнута отдельная приватная админка пользователей, чатов, медиа, жалоб на сообщения, серверных объявлений и журнала операций.

Сохранены Matrix, E2EE, звонки, Firebase и собственные уведомления, PIN,
крупные фото и видео, голосовые, архив и закрепление чатов, автоудаление,
пересылка, QR-контакты, код восстановления и встроенные GitHub-обновления.
Проверка обновления показывает изменения, затем предлагает фоновую загрузку.
Установку подтверждает Android.

Ключ восстановления сохраняйте отдельно от телефона: перевыпуск кода не
возвращает отсутствующие ключи сообщений. Админка не расшифровывает E2EE.
Автоудаление и удаление файла на сервере не гарантируют стирания чужих копий.
Объявления подчиняются настройкам уведомлений получателя. На другом homeserver
звонки и push требуют совместимой настройки.
