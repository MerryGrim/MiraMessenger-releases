# Mira Messenger — LAMBDADEV

## Release 0.13.0

[Скачать подписанный APK](https://github.com/MerryGrim/MiraMessenger-releases/releases/download/v0.13.0/MiraMessenger-release.apk)

Постоянный пакет `chat.mira.messenger`, versionCode15, Android8.0+, arm64/x86_64.
Устанавливайте поверх Release0.12 без удаления приложения. Существующий ключ
подписи сохранён. Старые MVP APK сохранены отдельными прежними релизами.

В этой версии:

- Срок автоудаления в каждом чате: час, сутки, 7, 30, 90 дней или год.
  На im.w2o.ru включён механизм Synapse без общего срока для существующих чатов.
- Выбор другого HTTPS homeserver на экране входа и подтверждаемая смена сервера.
- Полноценные страницы сервера, использования хранилища, версии и лицензий.
- Удаление аккаунта с точным Matrix ID, проверкой пароля и окончательным подтверждением.
  Неверный пароль не удаляет аккаунт; при неопределённом ответе ключи сохраняются.

Matrix, E2EE, звонки, Firebase, собственный канал уведомлений, голосовые,
пересылка, QR-контакты и встроенные GitHub-обновления сохранены.
Совместимость обычной переписки основана на Matrix. Push, скрытие присутствия
и служба звонков на чужом homeserver требуют совместимой настройки сервера.

Автоудаление и деактивация не гарантируют стирания чужих копий истории,
архивов, файлов и кешей других клиентов. E2EE-история требует пригодных ключей.
Перед выходом или удалением аккаунта сохраните необходимые данные и ключ восстановления.
Android подтверждает установку обновления; фоновое скачивание не заменяет это согласие.
