# Mira Messenger — LAMBDADEV

## Release 0.17.0

[Скачать подписанный APK](https://github.com/MerryGrim/MiraMessenger-releases/releases/download/v0.17.0/MiraMessenger-release.apk)

Постоянный пакет `chat.mira.messenger`, versionCode 19, Android 8.0+, arm64/x86_64.
Устанавливайте поверх Release 0.16 без удаления приложения. Постоянная подпись
сохранена; прежние APK остаются в предыдущих релизах.

В этой версии:

- Свайп вправо переносит чат в архив. После подтверждения есть пять секунд на отмену с обратным отсчётом.
- Несколько быстрых архивирований можно отменить вместе, пока их сроки не истекли.
- Архив открывается над списком чатов. Внутри можно искать, читать переписку и возвращать чаты свайпом вправо.
- Свайп влево закрепляет или открепляет чат. Закреплённые чаты остаются наверху в постоянном порядке.
- Те же действия доступны через удержание строки. Архивирование снимает закрепление; закрепление из архива возвращает чат в основной список.

Новые сообщения не извлекают чат из архива. Архив не удаляет историю и не
отключает уведомления. Признаки архива и закрепления используют стандартные
теги Matrix; порядок закреплений сохраняется отдельно для аккаунта и сервера
в этой установке, между устройствами он пока не синхронизируется.

Сохранены Matrix, E2EE, звонки, Firebase и собственные уведомления, быстрый
ответ и фото в шторке, PIN, голосовые, крупные фото и видео, автоудаление,
пересылка, QR-контакты, код восстановления и встроенные GitHub-обновления.
Проверка обновления сначала показывает изменения, затем предлагает фоновое
скачивание. Установку подтверждает Android.

Смена кода восстановления не возвращает отсутствующие ключи сообщений.
Сохраняйте код отдельно от телефона. Автоудаление не гарантирует удаления всех
чужих копий. На другом homeserver звонки и push требуют совместимой настройки.
