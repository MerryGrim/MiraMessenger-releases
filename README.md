# Mira Messenger · LAMBDADEV

Постоянная Android-версия: `chat.mira.messenger`, без `.debug`.
Исходники приватные, APK и манифест обновлений публикуются здесь.

[Скачать Release APK](https://github.com/MerryGrim/MiraMessenger-releases/releases/latest/download/MiraMessenger-release.apk)

Mira 0.12.0 добавляет пересылку одного или нескольких сообщений, включая
вложения, отдельную страницу создания группы, смену отображаемого имени,
контактные QR-коды, сканер камеры и распознавание картинки. Список блокировок
находится в настройках конфиденциальности; Избранное сохраняется в данных
Matrix-аккаунта и скрывается из общих чатов. Голосовые — AAC/M4A, моно,
24 кбит/с и 16 кГц; лишний резерв контейнера удаляется без повторного сжатия AAC.
На эмуляторе измерены около 7 КБ за 1,2 секунды и 33 КБ за 10 секунд.
Для последнего посещения менее суток назад показано время.

Пересылка вложений использует новую загрузку и режим шифрования целевого чата.
При переходе из секретного в обычный чат необходимо подтвердить предупреждение.
Опросы пока не пересылаются. Блокировка использует Matrix ignored users;
она не является запретом входа на сервер. QR контакта не переносит ключи.

Аватары, ответ свайпом, правка, удаление своих сообщений, реакции, форматирование,
голосовые и видеозвонки, E2EE, Firebase, собственный канал уведомлений и
обновление через GitHub сохранены. Для восстановления истории нужны ключи
или доступная пригодная резервная копия. Redaction не уничтожает сохранённые
копии на других устройствах и серверах. Автоудаление пока не включено.

Release 0.12.0/code14 устанавливается поверх Release 0.11.0 без удаления приложения.
Постоянный сертификат SHA-256:
`7e1a6e2805adb106e7e2f28e0dd956b9ce819f1e04a0964b27a3f46459ec5cf0`.
Android 8.0+, arm64 и x86_64. Старые MVP Releases сохранены отдельно.

Android потребует подтвердить установку. Проверки эмуляторов не подтверждают
плавность и фоновую доставку на каждом физическом телефоне; причина ранее
сообщённого выключения телефона не установлена.
