# Mira Messenger — LAMBDADEV

## Release 0.16.0

[Скачать подписанный APK](https://github.com/MerryGrim/MiraMessenger-releases/releases/download/v0.16.0/MiraMessenger-release.apk)

Постоянный пакет `chat.mira.messenger`, versionCode 18, Android 8.0+, arm64/x86_64.
Устанавливайте поверх Release 0.15 без удаления приложения. Постоянная подпись
сохранена; прежние APK остаются в предыдущих релизах.

В этой версии:

- Фото в развёрнутом уведомлении: миниатюра загружается через Matrix SDK, в том числе для E2EE, и добавляется без повторного сигнала.
- До десяти сообщений в карточке чата; разные чаты собраны в общую группу Mira. Смахивание обновляет сводку.
- Быстрый ответ на сообщение прямо из шторки Android. Ответ отправляется через
  текущую Matrix-сессию со связью с исходным сообщением; включённое в чате
  сквозное шифрование сохраняется. Открытая переписка и её черновик сохраняются.
- При включённом PIN ответ сначала открывается на отдельном экране после
  разблокировки Mira. Отправку нужно подтвердить; уведомление не обходит PIN.
- Если результат отправки неизвестен, Mira предлагает проверить чат и не
  повторяет сообщение автоматически. К защищённому черновику можно вернуться
  в течение суток; переключение аккаунта очищает ответы прежнего владельца.
- Установка, ввод, смена и отключение PIN получили общее оформление: точки
  вместо цифр, отдельная цифровая клавиатура и последовательные шаги. Смена
  начинается с проверки текущего кода. Существующие PIN из 4–12 цифр работают.
- Крупные превью фото и видео с сохранением пропорций. Полноэкранное фото с масштабированием, встроенное полноэкранное видео. Просмотр закрывается при блокировке и уходе в фон.
- Одинаковая аккуратная кнопка отправки в обычном режиме и форматировании.
- Сохранены светлая и тёмная темы, единые кнопки и настройка автоблокировки.

Matrix, E2EE, звонки, Firebase, собственный канал уведомлений, голосовые,
автоудаление, пересылка, QR-контакты, смена кода восстановления и встроенные
GitHub-обновления сохранены. Проверка обновления сначала показывает изменения,
затем предлагает фоновое скачивание. Установку подтверждает Android.

Быстрый ответ доступен для подтверждённых читаемых сообщений. Приглашения и
зашифрованные события без доступных ключей такой кнопки не получают. Android
может задерживать фоновую работу при отсутствии сети или ограничениях батареи.
Показ сведений на экране блокировки регулируется также настройками Android.

Смена кода восстановления не возвращает отсутствующие ключи сообщений.
Сохраняйте код отдельно от телефона. Автоудаление не гарантирует удаления всех
чужих копий истории. На другом homeserver звонки и push требуют совместимой
настройки сервера.
