# Element Call source

Mira 0.2.0-mvp embeds the official Maven artifact
`io.element.android:element-call-embedded:0.26.1`.
No changes to the upstream Element Call source have been made by this project.

The official upstream source for this dependency is:

- Project: [element-hq/element-call](https://github.com/element-hq/element-call).
- Release tag: [v0.26.1](https://github.com/element-hq/element-call/tree/v0.26.1).
- Exact commit: [9f7c35cd8f84b12f9395e6aac56fd396a3921482](https://github.com/element-hq/element-call/tree/9f7c35cd8f84b12f9395e6aac56fd396a3921482).
- [Source archive for that commit](https://github.com/element-hq/element-call/archive/9f7c35cd8f84b12f9395e6aac56fd396a3921482.tar.gz).
- [Embedded packaging/build instructions at that commit](https://github.com/element-hq/element-call/blob/9f7c35cd8f84b12f9395e6aac56fd396a3921482/docs/embedded_standalone.md).
- [Pinned dependency lockfile](https://github.com/element-hq/element-call/blob/9f7c35cd8f84b12f9395e6aac56fd396a3921482/pnpm-lock.yaml).

These links identify the official Element Call dependency and its corresponding
upstream source. They are not a claim that this public repository contains the
source for every component of the Mira application. Mira's Kotlin host bridge
is independently written against the public widget API. Source availability
and license obligations for a distributed integrated product must be addressed
for the actual release; an upstream link alone does not resolve that question.
